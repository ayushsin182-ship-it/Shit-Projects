# CP Lab

A local competitive programming mini project for macOS: import problems from Chrome, solve in VS Code, run samples and submit through your logged-in judge tab.

- [Download CP-Lab.zip](https://github.com/ayushsin182-ship-it/Shit-Projects/raw/refs/heads/cp-lab-mac-demo/CP-Lab.zip)
- [Mac installation guide](https://github.com/ayushsin182-ship-it/Shit-Projects/blob/cp-lab-mac-demo/CP-Lab/START-HERE-MAC.md)
- [Professor demonstration](https://github.com/ayushsin182-ship-it/Shit-Projects/blob/cp-lab-mac-demo/CP-Lab/PROFESSOR-DEMO.md)
- [Source code](https://github.com/ayushsin182-ship-it/Shit-Projects/tree/cp-lab-mac-demo/CP-Lab)

Supports Codeforces, AtCoder and LeetCode.com, with C++, Python and Java. Codeforces/AtCoder samples run locally; LeetCode examples use its own function harness. Judge submissions require an internet connection and your browser login.

Automated checks cover local compilation, pre-submit checks and simulated judge flows. Install and rehearse on your Mac before presenting; live judge compatibility has not been verified with your accounts.
